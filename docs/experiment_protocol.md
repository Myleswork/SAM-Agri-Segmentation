# 实验规范

六份配置覆盖两模型与三种输入。默认是随机权重 3 Batch smoke，不是训练对比结果。正式对比必须获得匹配预训练权重，统一数据划分、评价、输入尺寸和预算，记录上游源码、权重来源、归一化与随机种子。模型原生参数不同；同一模型的模态消融应只改变输入及其必要适配层。正式实验需要多个随机种子，报告均值及离散度。

WeedyRice 提供的划分保留用于基线，检查到 325 对同日连续编号跨集合，可能造成空间泄漏；需要另建并验证空间独立测试集。不要把现有 WEEDSBL 的指标当成严格公平基线。禁止在测试集上选阈值或依据测试分组调整训练。

Benchmark 是随机初始化结构计算成本，Eager、FP32/BF16、每种配置至少 30 次预热及 100 次测量。CUDA Event 测纯前向；端到端重复读取同一真实 RGB 图像并统计解码、缩放、归一化、H2D、前向、sigmoid/阈值和 D2H，不含结果保存。每批延迟及图片吞吐独立报告。不同尺寸的结果不可等同为公平对比。
